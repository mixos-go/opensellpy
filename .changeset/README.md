# Changesets

Halaman ini otomatis dibuat oleh [Changesets](https://github.com/changesets/changesets). Tujuannya
sebagai template untuk menulis changelog.

> Jangan di-edit manual. File `.changeset/<nama>.md` yang dibuat saat `pnpm changeset` bersifat
> sementara dan akan di-commit sebagai bagian dari PR-nya.
